# Stateless access tokens

## Context
[[tidewater/memory/decisions#ADR-009]] supersedes the Redis sessions of ADR-002.

## Solution
- Access token 15 minutes, refresh token 30 days, rotation on use.
- Gatekeeper devices get a scoped token per venue.

## Outcome
v1.8.1. Redis load dropped by a third.
