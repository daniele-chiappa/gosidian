# Payments v2

## Context
Paylane retires the v1 API at the end of 2026. v2 brings 3-D Secure 2 and saved payment methods.

## Solution
- New client package `internal/paylane/v2`, same idempotency rules ([[tidewater/memory/decisions#ADR-008]]).
- Behind `ff_payments_v2`; gradual rollout 1% → 10% → 50% → 100%.
- Webhooks v2 on a separate endpoint during the transition.

## Status
Staging complete. 10% of prod traffic since 2026-06-24. Next step 50% after one week without errors.
